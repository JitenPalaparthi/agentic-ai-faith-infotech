# Python Mathematics, Statistics, Matrices & Data Science Foundations

This is a **training-ready collection of 100 independent Python mini-projects**.

## Every example has its own folder

```text
001_mean/
├── README.md
├── main.py
└── requirements.txt
```

`README.md` explains the mathematics and formula.  
`main.py` is a clean runnable example with functions and a `main()` entry point.  
`requirements.txt` contains only the external packages required by that example.

## Curriculum progression

1. Statistics — mean, median, variance, standard deviation, percentiles, IQR,
   z-score, covariance, correlation, probability, distributions, sampling, bootstrap.
2. Vectors & matrices — magnitude, unit vectors, dot product, cross product,
   cosine similarity, matrix multiplication, inverse, determinant, rank,
   eigenvalues/eigenvectors, projections, SVD.
3. Algebra & calculus — slope, `y = mx + c`, quadratics, polynomials,
   exponential/log functions, sigmoid, derivatives, partial derivatives,
   integration and gradient descent.
4. Multidimensional arrays — 2-D/3-D/4-D arrays, axes, reshape, broadcasting,
   tensor-axis manipulation, masking and pairwise distances.
5. Analytics & regression — normalization, standardization, missing values,
   moving averages, least squares, residuals, MSE, MAE, R², multiple regression,
   covariance/correlation matrices, PCA foundations and more.

All `main.py` files are syntax-checked while generating the package.
See `INDEX.md` for the ordered list.
