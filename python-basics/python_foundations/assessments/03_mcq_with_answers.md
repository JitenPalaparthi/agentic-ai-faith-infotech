# MCQ Assessment

1. Which creates an immutable sequence?
   - A. list
   - B. tuple
   - C. set
   - D. dict
   Answer: B

2. Which keyword produces generator values?
   - A. return
   - B. send
   - C. yield
   - D. await
   Answer: C

3. Which is normally best for CPU-bound parallelism?
   - A. asyncio only
   - B. multiprocessing
   - C. a single thread
   - D. pathlib
   Answer: B

4. Which avoids SQL injection when used properly?
   - A. string concatenation
   - B. f-strings
   - C. parameterized queries
   - D. eval
   Answer: C

5. Which tool is commonly used for Python unit tests?
   - A. pytest
   - B. nginx
   - C. redis-cli
   - D. gcc
   Answer: A
