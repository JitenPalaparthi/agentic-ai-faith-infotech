# Capstone: Training Management API

Build a production-style training management service.

## Required Features
- Trainers, courses, batches, students
- CRUD APIs
- Validation
- PostgreSQL persistence
- Repository/service/API layers
- Logging
- Unit tests
- Integration tests
- Environment configuration
- Docker support
- Error handling
- Pagination
- Health endpoint

## Optional Extensions
- Authentication
- Role-based authorization
- Async database access
- Redis caching
- Background jobs
- OpenTelemetry
