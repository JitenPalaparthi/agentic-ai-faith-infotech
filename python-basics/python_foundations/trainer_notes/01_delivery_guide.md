# Delivery Guide

## Per Topic
1. Start with motivation / problem.
2. Show a minimal example.
3. Explain syntax.
4. Modify example live.
5. Ask learners to predict output.
6. Introduce a failure case.
7. Let learners fix it.
8. Give a lab.
9. Review common mistakes.

## Suggested Ratio
- 30% explanation
- 40% live coding
- 20% labs
- 10% review / assessment
